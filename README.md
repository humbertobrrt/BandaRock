
<h1> BandaRock </h1>
<h3> Apresentação do conceito de funções e métodos em Java para o Geração Caldeira </h3>
<p> Aqui, trabalhamos com os conceitos de herança e polimorfismo. </p>
<p> Temos a classe Artista e a Interface Funcao. </p>
<p> Além disso, temos as classes Vocalista, Guitarrista, Baixista e Baterista, onde todas elas implementam a interface Funcao, herdando o método executarFuncao, mas com seu próprio comportamento.</p>
